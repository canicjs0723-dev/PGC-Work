# 개선안 PPT 반영 결과

기준 자료: `1PGC_개선.pptx`의 8개 슬라이드. 원본 사진·브랜드 방향은 유지하고, 명시된 UX·콘텐츠 변경을 새 프로젝트 복사본에 반영했습니다.

| 슬라이드 | 요구사항 요약 | 적용 결과 | 확인 경로 |
|---|---|---|---|
| 1 | 통합 홈페이지의 브랜드·방향성 | 메인 사이트의 프리미엄 비즈니스 스테이 비주얼, 색상, 기존 사진과 여백 중심 레이아웃을 유지 | 전체 페이지 |
| 2 | Our Spaces 스크롤 전환으로 인한 탐색 방해 | 단계별 고정/핀 전환을 제거하고 일반 문서 스크롤 객실 카드로 교체. 카드 선택 시 객실 상세로 이동 | `/`, `/business-room`, `/guest-room` |
| 3 | 홈의 중복 소개·불필요한 공간 콘텐츠 정리 | 홈의 중복 객실 이미지 갤러리, 반복 시설·방문 정보 및 캠퍼스 소개 카드를 제거. 필요한 상세 정보는 객실·소개·가이드 페이지에 유지 | `/`, `/about`, `/guide` |
| 4 | 객실 명칭 변경 및 403호 용도 명확화 | 메뉴, 홈 카드, 상세 제목·캡션·연결을 PGC 403 Event Room / PGC 404 Guest Room으로 통일. 403호의 이벤트와 숙박 가능성을 모두 표시 | 헤더, `/`, 두 객실 상세 |
| 5 | 메뉴가 콘텐츠를 가리고 남는 문제 | 메뉴 선택 후 이동, 외부 영역 클릭, ESC, 다른 메뉴 선택 시 닫힘. 모바일 메뉴도 같은 방식으로 확인 | 데스크톱·모바일 헤더 |
| 6 | 추상적 설명을 구체적 공간 활용 사례로 변경 | Executive Stay는 404호 실제 수용 규모에 연결. Corporate Workshop, Partner Meeting, Team Offsite는 실제 장비·라운지를 갖춘 403호에 연결 | `/`, 두 객실 상세 |
| 7 | 객실 이미지 크기·정렬·탐색 개선 | 기존 사진을 유지하며 카드 비율을 통일하고 주요 사진을 `object-contain`으로 표시. 카드 클릭·좌우 화살표·ESC를 지원하는 갤러리 모달 추가 | `/business-room`, `/guest-room` |
| 8 | KR/EN 전환 및 언어 저장 | 후속 요청에 따라 한국어 버전·리소스·전환 UI를 제거하고 영문 단일 버전으로 정리. 기본 HTML 언어 `en`, 번역 전환 없이 전체 페이지 영어 렌더 확인 | 모든 페이지 |

## 삭제·보존 내역

- **삭제:** `SpaceScroller`, `SpacesGallery` 기반 홈 전환/반복 영역과 상세 페이지 내용을 되풀이하는 홈 블록.
- **보존:** 홈 히어로, 브랜드 이미지, 기존 사진, 소개·정체성 콘텐츠, 방문 안내와 시설의 상세 페이지 정보.
- **변경:** 객실 이름, 실제 용도 설명, 메뉴 닫힘 동작, 언어 전환, 갤러리 탐색.
- **후속 영문 전용 요청:** KR/EN 전환 및 한국어 콘텐츠를 제거하고, 서브페이지 Contact Us 배너는 제거하되 홈 배너와 공통 Footer, 독립 Contact 페이지는 유지.

## 배포 및 미검증 사항

- GitHub Pages workflow의 정적 빌드와 artifact 생성까지 성공했습니다. 실제 배포는 저장소 Settings → Pages에서 Source를 GitHub Actions로 설정한 뒤 확인해야 합니다.
- Formspree endpoint를 연결하고 `rondakorea@rondakorea.com`을 수신 이메일로 인증·선택했습니다. 실제 문의 내용의 이메일 실수신은 공개 사이트에서 제출 테스트 후 확인이 필요합니다.
- 개인정보 보유 기간, 운영 연락처, 원본 이미지의 외부 공개 권한은 운영 주체 확인 후 공개해야 합니다.
