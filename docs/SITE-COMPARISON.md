# 기존 사이트 및 신규 통합 사이트 비교

## 참고 기준

- 메인 사이트: [PGC 메인](https://jihyun37.github.io/pgc_site/) — 디자인·브랜드 기준
- 서브 사이트: [PGC 정보 사이트](https://jihyun37.github.io/PGC/#/) — 상세 콘텐츠·기능 기준
- 신규 복사본: `PGC_RENEWAL/` — 두 사이트의 정보 구조를 메인 디자인 시스템에 맞춰 통합

메인 프로젝트는 로컬 소스를 기준으로 살펴봤습니다. 서브 사이트는 공개 SPA 화면과 접근 가능한 콘텐츠를 기능 참고 자료로 확인했으며, 확인할 수 없는 동작이나 비공개 정보를 새 기능으로 추정하지 않았습니다.

## 통합 원칙 및 정보 충돌

- 사이트 간 객실 명칭은 개선안의 명시 지시에 따라 **PGC 403 Event Room**, **PGC 404 Guest Room**으로 통일했습니다.
- 403호는 이벤트룸 명칭만으로 숙박 여부가 모호하지 않도록 침대 5개와 숙박 가능 설명을 상세 페이지·홈 활용 사례에 표시했습니다.
- 404호 인원·시설은 프로젝트 자료의 최대 10명, 침대 9개, 욕실 2개를 기준으로 했습니다.
- 위치 자료에서 확인한 주소, 주차 사전 등록, 204동 측면 출입구 안내를 통합했습니다. 비공개 출입 코드와 Wi-Fi 자격 정보는 공개하지 않습니다.
- 개선안에서 삭제 대상으로 지정한 홈 중복 블록은 제거하되, 별도 통합 대상인 Identity & Concept, 방문 안내 및 객실 시설 상세는 해당 페이지에 유지했습니다.

## 검증 범위

- 로컬 브라우저에서 홈, 소개, 두 객실, 방문 안내, 위치, 문의, 개인정보 경로를 열어 렌더링을 확인했습니다.
- 모바일 폭에서 일반 페이지 스크롤, 가로 넘침 여부, 메뉴 열기·닫기와 객실 이동을 확인했습니다.
- 지도 주소 복사와 외부 지도 링크, 객실 갤러리의 다음 이미지·Escape 닫기를 확인했습니다.
- 영문 전용 정적 빌드에서 10개 HTML 문서를 생성했습니다. 홈, 소개, 403·404 객실, 방문 안내, 위치, 문의, 개인정보 등 8개 경로와 이미지 로딩을 로컬 정적 서버에서 확인했습니다.
- 문의 폼의 실제 제출은 로컬 브라우저에서 확인했으며, 발송 대상과 Formspree 응답은 운영 도메인 배포 후 실수신 테스트가 필요합니다.
- Pages 빌드와 artifact 생성은 성공했습니다. 실제 게시에는 저장소 Pages source를 GitHub Actions로 활성화해야 합니다.
- 하위 페이지 CTA는 About, Visitor Guide, Location, 403 객실, 404 객실에서 제거했습니다. 공통 Footer와 독립 Contact 페이지, 홈 CTA는 유지했습니다.
- 자세한 PPT 항목별 결과는 [PPT 반영표](./PPT-IMPLEMENTATION.md)를 참고하세요.
